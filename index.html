Prosedur update

  1. Buka repository GitHub tempat dashboard ini disimpan.
  2. Masuk ke folder input/, lalu upload/replace lima file Excel dengan nama persis seperti di atas.
  3. Setiap commit ke folder input akan memicu GitHub Actions untuk memproses data dan memperbarui data/data.json.
  4. Buka tab Actions di GitHub untuk memastikan proses Daily Portfolio Data Refresh berhasil.
  5. Setelah selesai, refresh dashboard. Data akan menampilkan timestamp pembaruan terbaru.

Catatan: menu ini merupakan panduan upload, bukan form yang mengirim file langsung dari browser. GitHub Pages tidak dapat menyimpan file ke repository tanpa autentikasi/backend. Jangan gunakan repository publik untuk file Excel yang berisi data mitra/BP sensitif.

Definisi dan batasan: NOA pada dashboard adalah jumlah loan_id unik; Mitra Unik adalah customer_number unik. Bucket ditentukan dari dpd_new. RR Flag adalah Paid NOA / Active NOA berdasarkan payment_min_1x, bukan otomatis RR resmi. Data pinjaman CLOSED dikecualikan dari kartu Active Loan. Total plafon pipeline bukan seluruhnya realisasi cair. Target RR/PQI belum ditampilkan sebagai pencapaian resmi sampai formula dan target operasional dikonfirmasi. Data dashboard merupakan agregasi; nama mitra, nomor telepon, dan ID personal tidak dipublikasikan.
